01 / SINTAXIS

Español natural y compacto

Puedes escribir «crear variable» o simplemente «variable». Las dos formas son válidas.

02 / TIPOS

Inferencia automática

Nexa detecta si una variable contiene un número, texto o valor lógico.

03 / PRIVACIDAD

Se ejecuta en tu navegador

El código de este playground se procesa localmente. No se envía a un servidor.

Empieza con lo básico

La gramática de Nexa 0.1 es pequeña a propósito.

Variables y operaciones

crear variable edad con valor 15
variable precio = 12
resultado = precio * 2
mostrar resultado

También puedes usar números decimales, textos, valores verdaderos y falsos.

Condiciones

si edad es mas grande que 18 haz:
    mostrar "Mayor de edad"
si no:
    mostrar "Menor de edad"
fin

También funciona la forma compacta: si (edad > 18):.

Repeticiones

repetir 3 veces:
    mostrar "Hola"
fin

variable i = 0
mientras i es menor que 3 haz:
    mostrar i
    i = i + 1
fin

Los bucles tienen límites de seguridad en esta versión experimental.

Entrada de datos

nombre = preguntar("¿Cómo te llamas?")
mostrar "Hola, " + nombre

# También puedes escribir:
preguntar "Tu ciudad:" y guardar en ciudad

El navegador mostrará una ventana para introducir el valor.
